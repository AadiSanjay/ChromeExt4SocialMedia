FocusTicker Privacy Policy
Last updated: October 1, 2026
FocusTicker is a browser extension designed to help users stay aware of the time they spend on supported websites.
Information FocusTicker processes
FocusTicker processes limited information necessary to provide its time-tracking functionality, including:
- The supported website/domain currently being viewed.
- The amount of time spent on supported websites.
- Current-session timing information.
- Extension preferences, such as the saved position of the FocusTicker timer.
How information is used
This information is used solely to provide FocusTicker’s core functionality, including displaying the current session timer, calculating daily website usage totals, and remembering extension preferences.
Data storage
FocusTicker V1 does not send website usage information to an external FocusTicker server.
Usage information and extension settings are stored using Chrome’s built-in extension storage APIs. Some interface preferences may use Chrome synchronized storage so that Chrome can preserve those preferences according to the user’s browser settings.
Data sharing
FocusTicker does not sell user data.
FocusTicker does not share user data with advertisers or data brokers.
FocusTicker does not use browsing information for advertising, profiling, credit decisions, or purposes unrelated to the extension’s functionality.
Website content
FocusTicker does not collect the contents of posts, messages, passwords, form entries, or other webpage content. Access to supported websites is used to display the FocusTicker interface and determine when a supported website is actively being used.
Third parties
FocusTicker relies on Chrome browser APIs to provide its functionality. Data stored through Chrome’s services may be subject to Google’s applicable privacy policies and user settings.
Data retention and deletion
FocusTicker stores only the information needed for its current functionality. Users can remove locally stored FocusTicker data by removing the extension and its associated extension data through Chrome.
Changes to this policy
This privacy policy may be updated if FocusTicker’s features or data practices change. Any updated version will describe the data practices applicable to that version of the extension.
Contact
Questions about this privacy policy can be directed to the developer through the support contact provided on the FocusTicker Chrome Web Store listing.
